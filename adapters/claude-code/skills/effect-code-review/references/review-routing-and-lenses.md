# Review Routing Predicates & 7-Specialist Lens Checklists

This reference defines the deterministic routing predicates returned by `harness_review_route` (`libs/harness/contract/src/review-routing.ts`, `libs/harness/decision/src/review-router-decision.ts`) and the surface checklists for all 7 specialist reviewers.

## 1. Observable Depth Gate (`skip | lite | focused | full`)

`harness_review_route` evaluates touched file paths, Nx `type:*` / `scope:*` tags, changed line count, and optional `clef-flash` (`ReviewRouterV1`) escalation (monotonic upward-only: the model can escalate `lite -> focused -> full` or add lenses, never downgrade deterministic selections). Specifically, `ReviewRouterV1` (`clef-flash`) evaluates `recommendedDepth` plus 5 semantic probability lenses (`security`, `reliability`, `adversarial`, `migration-contract`, `architecture` at `>= 0.75`), re-derives depth when added lenses increase selection count, and sets `source = "model-augmented"` only when depth or selections change:

| Depth     | Observable Trigger Predicate                                                                                                                                                                                                                                                                                                   | Orchestration Mode                                                                                                                                                        |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `skip`    | Non-empty diff where **every** file matches the non-governance documentation allowlist (`*.md`, `*.mdx`, `*.txt`, `LICENSE*` outside `adapters/`, `agent-patterns/`, and `docs/{specs,adr}/`), zero surface flags, and `changedLineCount < 40` (empty `changedFiles` or missing `changedLineCount` is rejected, never skipped) | Emit Section 1 receipt (`depth: skip`) and conclude.                                                                                                                      |
| `lite`    | Single file (`changedFiles.length === 1`), `changedLineCount < 40`, `1` selection, and no `focused`/`full` escalator (e.g. a small `< 40`-line localized change in a single `scope:web` component, single spec/ADR doc, single test file, or single non-doc config/script)                                                     | Single-pass read-only review using the primary matching lens; no subagent fan-out.                                                                                        |
| `focused` | Not `full`, and `changedFiles.length > 1`, `changedLineCount >= 40` (`< 180`), `2` selections, `hasAuthOrSecretSurface` (even `< 40` lines), `hasContractBoundaryChange` (even `< 40` lines), or manifest diagnostic warnings                                                                                                  | Dispatch only the signal-routed specialist subagent(s) (`Agent` tool with `model: "haiku"` or `"sonnet"`).                                                                |
| `full`    | `hasStatefulOrDeciderChange` (`type:core`, `type:domain`, `libs/es/`, deciders/outbox/projectors/gates), `hasMigrationOrInfraBindingChange` (`migrations/*.sql`, `*migrator*`, `alchemy.run.ts`), `touchedTiers.length >= 2`, `selections.length >= 3`, or `changedLineCount >= 180`                                           | Dispatch all routed specialists in parallel, including mandatory dual-review (`effect-ears-test-reviewer` + `effect-adversarial-reviewer`) for `type:core`/`type:domain`. |

## 2. 7-Specialist Signal-Routing & Lens Checklists

| Specialist Reviewer                      | Triggering Signals (Paths / Tiers / Content)                                                                                                                      | Core Hunting Checklist                                                                                                                                                                                                                                                                                                                                                                                          |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`effect-ears-test-reviewer`**          | `**/test/**`, `*.test.*`, `*.spec.*`, `docs/{specs,adr}/*.md`, plus `type:core`/`type:domain` dual-review                                                         | EARS 1:1 behavioral coverage, `Effect.flip`/`Cause.hasDies` negative tests, `it.effect.prop` decider boundaries, terminal-state preservation, span budgets (`SpanBudget.decide`), `8-Point Anti-Rubber-Stamp` Audit, `type:infra` guard-deletion falsification.                                                                                                                                                 |
| **`effect-adversarial-reviewer`**        | `type:core`, `type:domain`, `libs/es/`, `libs/harness/gates/`, `tools/oxlint/`, deciders/outbox/projectors                                                        | Inter-step crash sequences, duplicate/replay idempotency gates inside SQLite transactions, optimistic concurrency races, terminal state replay, SQLite fractional affinity, skeleton `E`-channel completeness.                                                                                                                                                                                                  |
| **`effect-security-reviewer`**           | Segment-bounded auth/session/token/secret/credential/permission paths, `Redacted`/`Config.redacted`/`idFromName`/IDOR/oauth/jwt in summary, or auth API contracts | IDOR / missing `actorId`/`tenantId` ownership checks, `Redacted.value` telemetry/error leaks, unbounded input schemas (`maxLength`, `maxItems`, `Finite`), client-supplied identity trust, indirect SQL/R2/DO ID injection.                                                                                                                                                                                     |
| **`effect-reliability-reviewer`**        | `type:infra`, `libs/*/infra/`, daemon/socket/subprocess/queue/alarm paths, `Scope`/`Schedule`/`withTransaction`/`DurableObject`/`D1Database`/`Queue`/`alarm`      | Async effects/`Schema.decode` inside `withTransaction`, in-memory `Ref` mutation before commit, unjittered/uncapped `Schedule.exponential`, missing external `Effect.timeout`, silent error drops in queues/alarms, missing W3C `traceparent`, `SqliteMigrator` table isolation.                                                                                                                                |
| **`effect-web-reviewer`**                | `scope:web`, `apps/*-web/`, `*.tsx`, `AtomHttpApi`/`useAtomValue`/`useAtomSend`                                                                                   | Raw `fetch`/ad-hoc `useEffect` loops bypassing `AtomHttpApi.make`, double-submit `useAtomSend` without pending/disabled guard, stale closures on parameterized query atoms, leaked listeners/timers, partial `Result`/`Option` `_tag` rendering instead of `match(...)...exhaustive()`, unvalidated `<Brand>.make(rawInput)` on forms/URLs.                                                                     |
| **`effect-migration-contract-reviewer`** | `migrations/*.sql`, `*migrator*`, `alchemy.run.ts`, `type:contract`, `libs/*/contract/`, `openapi*.{json,yaml}`, `HttpApi`/`RpcGroup`/`Schema.Tagged`             | Shared `SqliteMigrator` tracking-table collisions, unverified `UNIQUE`/`CHECK` constraints on live data, unindexed `WHERE`/`JOIN`/`ORDER BY` or unbounded `SELECT`s, contract-to-handler/client mismatches, broken Schema round-trips or explicitly declared upcaster chains, and `alchemy.run.ts` vs `Env` binding drift (scoping expand-contract checks strictly to explicitly shipped production databases). |
| **`effect-architecture-reviewer`**       | `type:service`, `adapters/`, `apps/harness-mcp/`, `apps/harness-cli/`, `libs/es/`, `libs/harness/`, `agent-patterns/`, or `changedLineCount >= 180`               | Business nouns (`Cart`, `Order`, `Album`) leaking into `libs/es/**`/`libs/harness/**` production `src/`, God-interface `Context.Service` ports, domain policy in `type:infra`, `Layer.fresh` around stateful resources, `() => Effect`/`Layer` thunks, `SKILL.md` SDO/parity drift, modules nearing `SelfDogfooding.decide` ceilings.                                                                           |
