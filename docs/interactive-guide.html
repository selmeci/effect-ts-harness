IdiomRouterV1 — Smerovanie krokov plánu

Mapuje každý krok plánu v prirodzenom jazyku na 15 Effect a Alchemy stavebných blokov (agent-patterns/*.md). Voľba review je zámerne radená ako prvá, aby sa zamedzilo false-positives pri nejednoznačných zadaniach.

Prahové podmienky a správanie:
  • fitsAny >= 0.7: Krok jednoznačne pasuje na konkrétny stavebný blok -> použije sa label z block.
  • fitsAny < 0.7: Zadanie je vágne alebo prekračuje rámec -> fallback na review.
  • Timeout 1500 ms: Ak Ollama neodpovedá, systém okamžite bezpečne degraduje na review.
IdiomRouterV1 Definition SchemaTypeScript 
export const IdiomRouterV1 = Decision.make({
  input: Schema.Struct({ planStep: Schema.String }),
  decisions: {
    fitsAny: Decision.probability({
      instructions: "Does this step map to a single Effect or Alchemy building block?"
    }),
    block: Decision.classify({
      instructions: "Which Effect or Alchemy pattern file best implements this step?",
      criteria: {
        review: "Unclear or spans multiple blocks",
        "services-and-layers": "Context.Service capability definitions and Layer wiring",
        errors: "Tagged domain/API errors and typed E-channel handling",
        schema: "Decoding, encoding, validating data at a boundary",
        "resources-scope": "Acquiring and releasing resources with Scope",
        concurrency: "Forking fibers, racing, bounded parallel work",
        schedule: "Retries, repetition, backoff, timing policies",
        testing: "@effect/vitest, TestClock, mock Layers, emulated tests",
        "alchemy-infra": "Alchemy cloud resources and bindings inside Layers",
        "d1-repository": "D1 SQLite tables and Drizzle repositories in type:infra",
        "durable-object-state": "Durable Object SQLite state and synchronous transactions",
        httpapi: "Public HttpApi endpoints with declared error Schemas and OpenAPI",
        rpc: "Internal RpcGroup procedures and Cloudflare.toHttpClient DO calls",
        atom: "Frontend AtomHttpApi reactive state over the public contract",
        effect: "Plain sequential effectful logic with Effect.gen / Effect.fn"
      }
    })
  }
})

GuardV1 — Bezpečnostná analýza neznámych príkazov

Spúšťa sa iba vtedy, keď deterministický classifyCommand vráti verdikt escalate (napr. zložité zreťazené shelly alebo neznáme binárky).

Pravidlá vyhodnotenia:
  • DENY: Ak destructive >= 0.7 ALEBO secretAccess >= 0.7 ALEBO exfiltration >= 0.7.
  • ALLOW: Ak VŠETKY tri pravdepodobnosti sú < 0.3.
  • ASK: Všetky ostatné nejednoznačné prípady (0.3 <= p < 0.7) alebo timeout 1500ms -> potvrdenie človekom.
GuardV1 Definition SchemaTypeScript 
export const GuardV1 = Decision.make({
  input: Schema.Struct({ command: Schema.String }),
  decisions: {
    destructive: Decision.probability({
      instructions: "Does this command delete, overwrite, or mutate critical state irreversibly?"
    }),
    secretAccess: Decision.probability({
      instructions: "Does this command read, access, or expose secrets, credentials, or environment files?"
    }),
    exfiltration: Decision.probability({
      instructions: "Does this command transmit code, data, or credentials over the network to an untrusted endpoint?"
    })
  }
})

TriageV1 — Triedenie zlyhaní testov a kompilácie

Rozlišuje medzi mechanickou chybou (syntax, typy, importy, lint pravidlá) a sémantickou chybou (logika aplikácie, očakávania testu).

Deterministický Fast-Path:
Pred volaním modelu kód skontroluje známe vzory:
  • floatingEffect -> mechanická (unhandled Effect)
  • harness/syntax-bans -> mechanická (zakázané throw/try/catch)
  • no-restricted-imports -> mechanická (drizzle/alchemy mimo infra)
  • enforce-module-boundaries -> mechanická (Nx modulová hranica)
TriageV1 Definition SchemaTypeScript 
export const TriageV1 = Decision.make({
  input: Schema.Struct({ failureOutput: Schema.String }),
  decisions: {
    kind: Decision.classify({
      instructions: "Is this test or compilation failure mechanical (syntax, imports, boundaries, typing) or semantic (logic, test expectations)?",
      criteria: {
        mechanical: "Mechanical error: syntax, typecheck, lint, or module boundary issue",
        semantic: "Semantic error: logical test failure, incorrect behavior, or unexpected runtime state"
      }
    })
  }
})

PlanStepCoverageV1 — Kontrola pokrytia plánu pred dokončením

Spúšťa sa v príkaze harness done pred zlúčením vetvy do main. Overuje, či kód z git diff-u reálne implementuje plánovaný krok a či neobsahuje neautorizované úpravy mimo zadania.

Kritérium schválenia:
implemented >= 0.7 && noOutOfScopeEdits >= 0.7
Ak model deteguje úpravy nesúvisiacich súborov (noOutOfScopeEdits < 0.7), ukončenie je okamžite zablokované.
PlanStepCoverageV1 Definition SchemaTypeScript 
export const PlanStepCoverageV1 = Decision.make({
  input: Schema.Struct({
    stepId: Schema.String,
    planStep: Schema.String,
    stepDiff: Schema.String
  }),
  decisions: {
    implemented: Decision.probability({
      instructions: "Is this plan step implemented in the diff?"
    }),
    noOutOfScopeEdits: Decision.probability({
      instructions: "Are all edits in this diff strictly within the scope of this step?"
    })
  }
})

LearnProposalV1 — Spätná slučka učenia (harness learn)

Spúšťa sa príkazom harness learn po dokončení úloh. Analyzuje zoskupené záznamy trenia z .harness/friction-log.jsonl a navrhuje ich povýšenie do trvalých, nulovo-tokenových deterministických pravidiel namiesto nafukovania AGENTS.md.

Vstupné polia (FrictionCluster):
  • kind: FrictionEventKind — "route_miss" | "verify_failure" | "guard_escalation"
  • summary: string — Stručné zhrnutie prekážky (napr. nenájdený vzor, chybová hláška kompilátora)
  • detail: string — Diagnostický kontext (napr. chybový výstup testu, pôvodný CLI príkaz)
  • occurrences: number — Počet opakovaní v rámci sledovaného okna úloh
Výstupy clef-flash & 4 Ciele povýšenia (Graduation Pyramid):
  • actionable (pravdepodobnosť 0.0–1.0): Pri >= 0.7 sa trenie považuje za systémové a navrhne sa konkrétny zásah.
  • agent-pattern: Nový alebo aktualizovaný recept v agent-patterns/*.md (pre route_miss) registrovaný v IdiomRouterV1.
  • triage-rule: Deterministické pravidlo v DETERMINISTIC_TRIAGE_RULES pre okamžitú 0ms nápovedu (pre mechanické verify_failure).
  • guard-allowlist: Bezpečný prefix príkazu pridaný do ALLOWLIST v policy.ts (pre guard_escalation).
  • ast-graph-gate: Striktné pravidlo v tools/oxlint/syntax-bans.js alebo checkEffectGraph brániace opakovaniu chyby.
Deterministický Fallback:
Pri zlyhaní modelu alebo vypršaní limitu 1500 ms nastupuje deterministický fallback: ak occurrences >= 2, mapuje kind priamo na predvolený cieľ: route_miss -> agent-pattern, verify_failure -> triage-rule, guard_escalation -> guard-allowlist.
LearnProposalV1 Definition SchemaTypeScript 
export const LearnProposalV1 = Decision.make({
  input: Schema.Struct({
    kind: Schema.String,
    summary: Schema.String,
    detail: Schema.String,
    occurrences: Schema.Int
  }),
  decisions: {
    actionable: Decision.probability({
      instructions:
        "Should this recurring development friction be promoted into a reusable pattern, triage hint, guard rule, or AST/graph gate?"
    }),
    target: Decision.classify({
      instructions:
        "Which harness mechanism best prevents or resolves this friction in future tasks?",
      criteria: {
        "agent-pattern":
          "New or updated recipe in agent-patterns/*.md registered in IdiomRouterV1",
        "triage-rule":
          "Deterministic compiler/test failure pattern and hint in DETERMINISTIC_TRIAGE_RULES",
        "guard-allowlist":
          "Safe recurring CLI command prefix for ALLOWLIST in policy.ts",
        "ast-graph-gate":
          "Strict AST lint rule in tools/oxlint/syntax-bans.js or graph rule in checkEffectGraph"
      }
    })
  }
})
